# Agents

Bossnu Unified defines six roles:

1. Planner: decomposes the goal into executable steps.
2. Builder: implements code or configuration changes.
3. Researcher: gathers relevant repository or external knowledge.
4. Operator: executes approved tools and deployment actions.
5. Reviewer: inspects results, tests, and failures.
6. Verifier: checks that the requested outcome actually exists.

Agents are routed by the Core. A task may use one or multiple agents.
